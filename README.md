## Practical questions

**Windows says the file is blocked. Which setting clears that?**

Right-click on the file, select Properties, then check the Unblock option. After that, start `setup` again.

**Will a USB stick work if I leave the folder on it?**

Yes, if the USB stick is writable. The first start is slower.

**I launched from the still-zipped archive and got nowhere. What step was missing?**

The unpack was missing. Until that finishes, `setup` is not yet a normal file in a normal folder.

**One change is all I want. Does that fit in a single issue?**

A single issue can hold it, as long as the text is the one thing you wanted.

**Can a code edit of the published files stand as the request?**

It cannot. The request belongs in an issue, because publication here is a finished build.

**The zip created an extra nested folder. Which level do I open?**

Open the folders until you find `setup` and the other files together in the same one.
